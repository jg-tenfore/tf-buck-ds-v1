The interactive prototype is a working, self-contained walkthrough of the back-office. It renders the
dual-tier Global Nav once and drives navigation entirely client-side. It reuses the *exact* same screen
components documented here under **App Screens**, so the prototype and the component library never drift
apart. Any nav destination that isn't designed yet shows a clear "not built" placeholder instead of dead-ending.

**How to open it** — it lives on its own site, separate from this Storybook:

- Live app: <a href="https://tf-buck-prototype.netlify.app" target="_blank" rel="noreferrer"><strong>tf-buck-prototype.netlify.app</strong></a> (auto-deploys on every push to <code>main</code>).
- Run it locally with <code>npm run app</code> (serves on port 6019; Storybook stays on 6018).
- Hover a top-level section to reveal its sub-items, then click to navigate; press <kbd>⌘K</kbd> / <kbd>Ctrl-K</kbd> to jump to any screen by name.

## What this is

This Storybook is the single source of truth for the **Buck Design System** — the tokens, primitives,
and component library that new Tenfore product screens are built from. It shares its color palette and
typography with the Fox design system, on the same Tailwind v4 + React Aria foundation.

## The map

| Category | What's inside |
| --- | --- |
| **Foundations** | Design tokens & primitives — Colors, Typography, Spacing, Radius, Border, Effect Styles, Icons, and Logos. |
| **Components** | The full kit — Actions, Forms, Feedback & Status, Layout & Structure, Media & Visuals, and Navigation. |
| **Sign in / Sign up** | Authentication flows — Log in, Sign up, Forgot password, Verification. |

## How it's built

- **React 19** + **TypeScript** throughout
- **Tailwind CSS v4** with a semantic, light/dark-aware token system (`src/styles/theme.css`, `palette.css`)
- **React Aria Components** as the accessibility foundation (imported as `Aria*`)
- **Storybook 10** (`@storybook/nextjs-vite`) for documentation and visual testing

### Conventions

- Files are **kebab-case**; React Aria imports are prefixed **`Aria*`**.
- Style with **semantic tokens** (`text-secondary`, `bg-primary`) — never literal color classes.
