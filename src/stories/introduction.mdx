## What this is

This Storybook is the single source of truth for the **Buck Design System** — the tokens, primitives,
and component library that new Tenfore product screens are built from. It shares its color palette and
typography with the Fox design system, on the same Untitled UI + Tailwind v4 + React Aria foundation.

## The map

| Category | What's inside |
| --- | --- |
| **Foundations** | Design tokens & primitives — Colors, Typography, Spacing, Radius, Border, Effect Styles, Icons, and Logos. |
| **Components** | The full kit — Actions, Forms, Feedback & Status, Layout & Structure, Media & Visuals, and Navigation. |
| **Sign in / Sign up** | Authentication flows — Log in, Sign up, Forgot password, Verification. |

## How it's built

- **React 19** + **TypeScript** throughout
- **Tailwind CSS v4** with a semantic, light/dark-aware token system (`src/styles/theme.css`, `palette.css`)
- **React Aria Components** as the accessibility foundation (imported as `Aria*`)
- **Storybook 10** (`@storybook/nextjs-vite`) for documentation and visual testing

### Conventions

- Files are **kebab-case**; React Aria imports are prefixed **`Aria*`**.
- Style with **semantic tokens** (`text-secondary`, `bg-primary`) — never literal color classes.
